# Изоляция выполнения · повторно проверено

Код обработки данных, обучения и проверок запускался под sandbox-exec macOS с deny-default. Для этой проверки доступ файлового инструмента агента не использовался как замена песочнице: каждый запуск кода явно помещался в неё.

Профиль разрешает чтение и запись рабочей папки, чтение необходимых системных библиотек и установленных компонентов Python/Homebrew Cellar. Чтение файловых метаданных разрешено загрузчику. Это не виртуальная машина и не запрет чтения вообще любых системных файлов.

Проверено с безопасным контрольным файлом вне рабочей папки:

1. Запрещены чтение и запись вне рабочей папки.
2. Запрещены чтение исходного ZIP в Downloads и перечисление домашней папки.
3. Запрещено чтение каталогов /private/etc и /opt/homebrew/etc. В первой версии они были излишне доступны.
4. Симлинк из рабочей папки не даёт прочитать внешний файл.
5. Запрещены внешний TCP, localhost TCP и Unix-сокет. Проверялась именно ошибка запрета доступа, а не тайм-аут.
6. Дочерний Python наследует запрет чтения внешнего файла.
7. Окружение очищено; Python запускается с -I -S, без стороннего sitecustomize и пользовательских путей импорта.

Всего 13 успешных проверок, машинный результат — security_checks.json. Контрольный файл не изменился, попытка внешней записи не создала файл. Метаданные файлов вне рабочей папки не скрываются.

Доверенный код передавал входной ZIP в рабочую папку и готовый комплект обратно в Downloads. Эти копирования не предоставляли коду решения доступ к прочим личным файлам. При первоначальном выполнении файлы задания не отправлялись на внешние сервисы; проверялся только публичный текст правового правила без паспортных данных в запросах. Последующее размещение комплекта в приватном GitHub-репозитории разрешено пользователем отдельно и выполняется вне песочницы обработки. Obsidian не читался и не изменялся в ходе выполнения и повторной проверки задания.

Для воспроизведения ограничения используйте `sh run-isolated.sh input.jsonl output.jsonl`. Обычная команда `python postprocess.py ...` сама по себе песочницу не включает. Вход и выход должны быть внутри папки решения. Launcher генерирует профиль для текущего расположения папки.
