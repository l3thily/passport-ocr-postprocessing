# Проверенная изоляция

Обработка данных, обучение, проверка и запуск штатного evaluate.py выполнены под `sandbox-exec` macOS с политикой deny-default.

- Чтение содержимого личных файлов в `/Users` запрещено. Проверены отказы для домашнего файла, исходного ZIP в Downloads и заметки Obsidian.
- Сетевые соединения запрещены; проверено, что TCP-подключение к внешнему адресу блокируется.
- Чтение данных и запись результатов разрешены только внутри отдельной рабочей папки. Для работы интерпретатора доступны системные каталоги и Homebrew; файловые метаданные доступны загрузчику.
- Финальный запуск и тесты выполнялись с очищенным окружением через `env -i`, Python — с флагом `-I`.
- Никакие исходные данные задания не отправлялись на внешние сервисы. Для правового правила проверялся только публичный текст постановления; паспортные поля в запросы не включались.
- Obsidian в ходе выполнения задания не читался и не изменялся. Результаты в базу знаний не записаны.

Исходный ZIP был скопирован в рабочую папку доверенным кодом до запуска обработки. После проверки доверенный код скопировал выбранные результаты в Downloads. Эти операции передачи не давали коду решения доступа к остальным файлам пользователя.

`run-isolated.sh` создаёт такой же профиль для папки решения. Стандартная команда Python сама по себе не включает песочницу: для повторения изоляции используйте launcher. Это изоляция средствами ОС, не отдельная виртуальная машина.
