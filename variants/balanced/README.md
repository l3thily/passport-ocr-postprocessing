# Вариант `balanced`: основной

`answers.jsonl` в этой папке: 868 принятых документов из 2000 (43.4%). Ожидается 4.6 ошибки, 90% интервал 1–12. Этот же файл лежит в корне репозитория как основной ответ.

Запуск: `python postprocess.py data/test_predictions.jsonl answers.jsonl` (вариант по умолчанию).

## Что принимается

Документ принимается, если подтверждено каждое из 10 полей.

Номер паспорта, дата рождения, дата выдачи, код подразделения и пол берутся из второй строки МЧЗ с верными контрольными цифрами. Визуальная зона тут запасная. Её значение подставляется только в один сломанный сегмент МЧЗ, и то если подстановку подтверждают контрольные цифры самой МЧЗ.

ФИО должно совпасть в визуальной зоне и в первой строке МЧЗ. Расхождение допускается, только когда одна зона уверена (≥0.99), а другая сомневалась (<0.9) ровно в тех символах, где они расходятся.

Место рождения и ведомство нужны с уверенностью каждого символа не ниже 0.95 для web и mobile и не ниже 0.9999 для mobile_v2. Неуверенное ведомство можно подтвердить словарём написаний для этого кода подразделения из разметки train.

Паспорт должен быть действителен на 01.10.2026 без опоры на 90-дневную отсрочку после 20 или 45 лет.

И последнее правило, которым вариант отличается от `max50`: web-документ отклоняется, если больше 28% символов его визуальной зоны прочитаны с уверенностью ≥0.9999.

## Когда выбирать

Когда ошибка заметно дороже отказа, но не катастрофична. Против `max50` этот вариант теряет 133 документа и избегает примерно 3.3 ошибки, то есть около 40 пересъёмок на одну предотвращённую ошибку. Против `zero` он принимает на 562 документа больше ценой примерно 4 ошибок.
