# Вариант `zero`: почти без ошибок

`answers.jsonl` в этой папке: 306 принятых документов из 2000 (15.3%). Ожидается 0.5 ошибки, 90% интервал 0–3. Вероятность обойтись совсем без ошибок около 53%.

Запуск: `python postprocess.py data/test_predictions.jsonl answers.jsonl --variant zero`.

## Что принимается

Только документы web, и только те, где меньше 28% символов визуальной зоны прочитаны с уверенностью ≥0.9999. Остальные проверки те же, что в основном варианте: номер, даты, код и пол берутся из МЧЗ с верными контрольными цифрами, ФИО совпадает в двух зонах, место рождения и ведомство прочитаны с уверенностью не ниже 0.95, паспорт действителен на 01.10.2026.

mobile и mobile_v2 этот вариант не принимает совсем. Дело не в качестве распознавания, оно у них не хуже. Но там встречаются ошибки разметки, при которых обе зоны уверенно согласны между собой (2 на 551 принятый документ mobile и 2 на 149 mobile_v2 при кросс-валидации), и ничто во входных данных их не выделяет. Убрать такие ошибки можно, только отказав всему источнику.

## Когда выбирать

Когда одна принятая ошибка стоит дороже примерно 140 пересъёмок. Именно столько документов (562) этот вариант теряет по сравнению с `balanced`, чтобы избежать около 4 ошибок. Учтите и то, что ноль ошибок он не гарантирует: шанс примерно пятьдесят на пятьдесят. Частота ошибок оценена по одной ошибке на 573 документа, и правило про насыщенную уверенность найдено на тех же данных.
