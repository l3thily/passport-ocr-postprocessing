# Повторная проверка · 22 октября 2026

Повторная проверка выявила технические ошибки и завышенную уверенность в статистических выводах первой версии. Код исправлен, исходные данные не изменялись. Число принятых test изменилось с 86 до 79.

## Подтверждённые дефекты и исправления

| Проблема первой версии | Проверка и исправление |
|---|---|
| NaN в confidence приводил к NaN в score, а сравнение с порогом не отклоняло документ | Старая версия принимала контрольный пример; новая отклоняет неконечные числа во всех полях |
| Отсутствующие вероятности символов ФИО или МЧЗ могли пройти отбор | Проверяются типы, диапазоны и длины всех массивов, а не только места рождения |
| Числовая нормализация удаляла произвольные буквы | Контрольный номер с добавленным XYZ принимался; теперь не проходит формат |
| Усечённая строка ФИО считалась полным подтверждением | Пример со скрытым окончанием принимался; теперь отклоняется |
| Точное название ведомства искалось глобально, без его кода | Точное совпадение проверяется внутри конкретного кода; все 7 изменений в test вызваны этой проверкой |
| Модель без политики могла работать с ослабленными условиями | Неполный или некорректный загруженный артефакт останавливает инференс |
| Ноль ошибок после уточнения порога по проверочному блоку подавался слишком уверенно | Отчёт прямо указывает подбор правил на проверочных данных; статистические границы и байесовское ожидание из них удалены |

Пять воспроизводимых регрессионных примеров в `review_changes.json` показывают переход accept → reject. Они проверяют поведение кода; они не доказывают ошибки в семи реальных тестовых документах, для которых разметка неизвестна.

## Что проверено фактически

- Все 7 файлов исходного задания совпали с ZIP побайтово по SHA-256. Начальный комплект также соответствовал своему манифесту.
- 19 тестов правил прошли. Включены зафиксированные строки МЧЗ из данных, а не только строки, сгенерированные проверяемой функцией.
- 6 проверок CLI прошли: идентичные ответы, атомарный отказ при дубликатах, испорченном JSON и записи не-объекта, запрет перезаписи входа, работа без файлов обучения.
- 2000 ответов проверены отдельным кодом на схему, порядок, уникальность doc_id и доступные признаки срока действия.
- Исходный evaluate.py подтвердил 158/0 на train и 105/0 для сохранённых ответов пяти разбиений. Независимая проверка дат совпала для всех принятых.
- 13 проверок песочницы прошли, в том числе обход через симлинк, дочерний процесс, TCP и Unix-сокет. Контрольный файл за пределами песочницы не изменился.

## Что не доказано

Нет независимого доказательства нулевой ошибки на test. Новые разбиения того же просмотренного train не устранят историю подбора правил. Нет доказательства оптимальности покрытия 3.95%; почти все документы отклоняются, mobile_v2 не принимается. Не проверяется реестровая действительность паспорта. Согласованная ошибка двух OCR-зон может остаться незамеченной.
