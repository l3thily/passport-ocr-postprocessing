# Постобработка OCR паспорта РФ

Офлайн-решение на стандартной библиотеке Python 3.10+. На CPU, без установки пакетов и сетевых запросов.

```sh
python3 postprocess.py data/test_predictions.jsonl answers.jsonl
```

На macOS можно запускать с блокировкой личных файлов и сети:

```sh
sh run-isolated.sh data/test_predictions.jsonl answers.jsonl
```

Скрипт песочницы использует Homebrew Python `/opt/homebrew/bin/python3`.
Другой установленный интерпретатор: `OCR_PYTHON=/путь/python3 sh run-isolated.sh ...`.
Вход и выход при изолированном запуске должны находиться в папке решения.

Результат: 2000 строк, 86 `accept`, 1914 `reject`; поля только у принятых.
Краткий отчёт: [REPORT.md](REPORT.md). Полные метрики: [metrics.json](metrics.json).

## Как работает

1. Проверяет качество снимка, наличие полей, количество и геометрию строк; сортирует строки по координате Y.
2. Нормализует пробелы, регистр и формат цифровых полей. Сохраняет исходное написание текстов, включая латинские названия мест рождения.
3. Проверяет календарные даты и возрастной срок действия на **01.10.2026** с 90-дневным переходным сроком после 20 и 45 лет. Это проверка доступных признаков, а не запрос в реестр действительности паспортов.
4. Проверяет две строки МЧЗ, четыре контрольные цифры и полное согласие с визуальными ФИО, полом, датами, кодом подразделения, серией и номером.
5. Использует обученные на train варианты названий подразделений. Исправляет только короткие однозначные расхождения; справочник DaData не подменяет написание документа своими грамматическими формами. Для новых названий требуется высокая посимвольная уверенность.
6. Применяет отдельные пороги для источников снимка. Суммарная неопределённость и массовое насыщение уверенности служат признаками риска. Этот score не является вероятностью ошибки.

Веса нейросетей не нужны. `model.json` содержит словарь ведомств и пороги, не содержит ФИО или паспортных номеров из train. Во время инференса разметка не читается. Справочник `reference/subdivisions.csv` и `model.json` ищутся относительно кода, вход/выход — относительно текущей папки.

## Воспроизведение

```sh
python3 train.py
python3 tests.py
python3 evaluate.py train_answers.jsonl data/train_labels.jsonl
```

`train.py` переобучает словари и пороги в каждом из пяти разбиений, затем обучает финальный артефакт на всём train и формирует ответы. Разбиение: первые 8 hex-цифр SHA-256(doc_id), остаток от деления на 5. Test не используется для подбора порогов, его разметки в архиве нет.

Контрольные проверки: даты и переходные сроки, испорченная контрольная цифра, несогласие ФИО, пропавшие/переставленные строки, рассогласованные уверенности, неизвестный источник, сохранение латинских текстов. Выход записывается атомарно; дубликаты doc_id и совпадение путей входа/выхода запрещены.

Нулевая ошибка внутренней проверки не доказывает нулевую ошибку test. Разведочный анализ и уточнение правил проводились на этом же train; это прямо отражено в отчёте. История промежуточной политики с ошибкой сохранена в `experiments/previous_policy_metrics.json`.

## Состав

- `postprocess.py`, `core.py` — применение решения;
- `train.py`, `tests.py`, `model.json` — обучение, проверки и готовый артефакт;
- `answers.jsonl` — результат для test;
- `REPORT.md`, `metrics.json`, `verification.json` — отчёт и результаты проверок;
- `data/`, `reference/`, `TASK.md`, `evaluate.py` — исходные материалы задания;
- `run-isolated.sh`, `ISOLATION.md` — изолированный запуск и описание проверки.

Репозиторий локальный. Удалённый репозиторий не создавался, публикации исходных данных не было. `data/` исключена из Git, но включена в локальный ZIP для воспроизводимости. Справочник распространяется с исходным указанием CC BY-SA 4.0, см. `reference/SOURCE.txt`.
